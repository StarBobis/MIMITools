## 功能定位

MIMITools 是围绕 **3Dmigoto 系加载器生态**打造的 Mod 分析与格式转换工具箱。目前可用的核心模块是：**Mod 分析、手动格式转换、自动格式转换与原神防报错**。

它不是某个单一功能的脚本合集，而是一套面向玩家、Mod 新手与 Mod 作者的桌面工具。

## 产品介绍

3Dmigoto Mod 生态繁茂，却长期缺少趁手的工具：游戏版本更新可能让旧 Mod 一夜失效；复杂 Mod 的 `ini` 动辄几千行；数据类型匹配错误会让模型花屏、变形；普通玩家遇到原神报错，也只能四处求助。

MIMITools 想把这些事收拢到一个桌面应用里。

### 🔍 Mod 分析（可视化格式转换工作台）

这是 MIMITools 最强大、也最直观的格式转换入口。选中 Mod 目录并选择游戏预设后，所有解析结果都会呈现在同一个可视化工作台里：

- **自由搭配资源**：把解析出的 IndexBuffer、VertexBuffer、贴图分配到对应的 DrawIB 分组，也可以随时移除或停用；
- **直观调整数据类型**：每个分组都可以手动切换数据类型，也可以一键自动识别；Buffer 与分类不匹配时，直接重新指定，3D 预览会立即更新；
- **贴图可视化调试**：可以给整个 DrawIB 或单独某个 Submesh 上贴图，切换 UV、拆分 DrawIndexed、开关网格线，边看边调；
- **多来源与变量切换**：同一组可以切换不同 LOD/来源，也可以切换 Mod 的变量组合，快速定位问题；
- **确认后一键导出**：预览满意后直接导出，衔接手动格式转换流程，得到可导入 Blender 的模型文件。

换句话说，Mod 分析不只是「看结构」，而是把格式转换过程中最费神的 Buffer 对应关系、数据类型选择和贴图匹配，变成了看得见、点得动、马上出结果的操作。

### ✋ 手动格式转换

手动格式转换以 **DrawIB** 为单位逐组还原模型，工具会自动匹配数据类型，并输出可导入 Blender 的模型文件，方便继续加工。

它是功能最完整的转换路径，适合处理复杂、极端或自动格式转换暂时覆盖不到的 Mod；代价是需要手动选择文件。

### 🤖 自动格式转换

自动格式转换只需选择 Mod 的 `ini` 文件，无需开启游戏，即可一键转换模型。支持通用 Mod 与 WWMI、EFMI 等专项格式，完成后还会自动转换贴图预览，方便在 Blender 中快速上贴图。

### 🛡️ 原神防报错

内置**第六代原神 Mod 防报错技术**，帮助减少游戏运行 Mod 时的报错与崩溃。该功能需要 LTS 授权。

## 关于「格式转换」：我们想说的话

社区里习惯把这类工具叫做「逆向」，但这个名字其实言重了：MIMITools 做的事情，只是把 Mod 中的模型数据从一种格式**转换**为可编辑的格式，让模型可以被理解、被修复、被继续创作。也请先记住一个事实：**MIMITools 从来不是用来偷别人 Mod 模型的工具。**

这个过程的价值，从来不在「拿走别人的东西」，而在于：

- **修复权重破损的旧 Mod**：游戏更新后，旧 Mod 的权重和模型数据可能失效、变形。格式转换能把这些数据重新还原出来，让旧作品有机会被修复，也让旧 Mod 在新版本中重新可用。
- **学习 UV 布线等制作技法**：通过观察一个 Mod 的数据组织方式，理解角色模型如何拆 UV、如何排布线、如何绑定骨骼，这是新手成长最直接的教材。
- **兼容与二次创作**：在获得授权的前提下，对已有 Mod 进行适配、修复与再创作，让社区的作品延续，而不是随版本更新一起消失。

我们反对任何把格式转换等同于「盗模型」的偏见，也同样反对把工具用于窃取他人劳动成果的行为。**技术是中性的，使用技术的人才需要底线。** MIMITools 选择站在「修复、学习、兼容」这一边。

## 为什么部分 Mod 作者会抵制这样的工具

一些 Mod 作者对格式转换工具抱有明显的敌意。表面上，他们的理由是「保护创作者权益」；但真正让这类工具被抵制的核心原因，是它**打破了 Mod 作者对自己模型修改的垄断权**。

在旧生态里，一个 Mod 只有作者本人能改、能修、能解释；别人一旦失去源文件，就只能求助于作者。格式转换工具的存在，让修复与学习不再依赖某个人的恩赐，也自然让「独家修改权」不再成立。

但我们需要正视一个更根本的事实：**Mod 作者制作 Mod 的过程，本身就是在未经授权的情况下使用游戏公司的模型、贴图与资源。** 从严格的法律角度看，绝大多数 Mod 制作都建立在侵权基础之上，Mod 作者的作品并不因此天然拥有合法版权，所谓「版权保护」的主张，也往往缺乏坚实的法律根基。

既然大家的创作都站在同一片灰色地带，就谈不上谁比谁更高贵。我们尊重每一位 Mod 作者的劳动，但反对以「版权」之名维护垄断、阻碍社区学习与修复。真正健康的社区，应当允许知识流动，允许作品被理解，也允许技术为所有人服务。

## 常见问题

### MIMITools 是拿来偷别人 Mod 模型的吗？

不是。MIMITools 的核心目标是**分析、修复、学习与兼容**，而不是提取与盗用。我们明确反对把格式转换工具用于窃取他人的劳动成果；同时也相信，因为有人滥用就否定整个技术方向，是对社区发展不负责的做法。

### 为什么有些 Mod 作者反对这类工具？

正如上文所说，表面理由是保护权益，核心其实是维护对模型修改的垄断权。而 Mod 制作本身大多建立在未经授权使用游戏资源的基础上，作品并不具备干净、合法的版权基础。因此，以版权之名阻止他人修复与学习，既站不住脚，也不利于社区生态。

### Mod 分析和格式转换需要开启游戏吗？

分析 Mod 目录与自动格式转换都不需要开启游戏；手动格式转换只需把对应文件拖入工作空间，同样不需要游戏运行。

### 自动格式转换和手动格式转换有什么区别？

自动格式转换适合批量、快速的场景：选择 `ini` 文件后一键转换。手动格式转换则适合复杂、极端或自动策略覆盖不到的 Mod，可以逐步处理。

### 转换出来的模型能导入 Blender 吗？

可以。格式转换输出为 Blender 可用的模型文件，导入后可以继续编辑、上贴图、修权重或重新导出。

### 支持哪些游戏？

支持原神、鸣潮、绝区零、星穹铁道、崩坏三、异环、终末地等 20+ 款游戏，具体列表见上文「支持的游戏预设」。

### 原神防报错是免费功能吗？

不是。原神防报错属于 LTS 授权功能；Mod 分析、自动格式转换等核心能力同样需要 LTS 授权。授权机制是为了保障正常用户权益，防止工具被恶意倒卖。

### 转换一个 Mod 会把游戏搞坏吗？

不会。MIMITools 只做离线分析与数据转换，不修改游戏本体，也不触碰游戏文件。

### 我完全没有基础，能用吗？

能。自动格式转换与防报错功能都面向普通玩家，按文档操作即可；如果你愿意进一步学习，手动格式转换功能也会逐步引导你理解整个流程。从「能用」到「会做」，MIMITools 给你留好了成长空间。
