## 功能定位

MIMITools 专注于**二次元游戏 Mod 的分析与逆向**，围绕 3Dmigoto 系加载器生态打造。无论你是想分析一个复杂 Mod 的结构、修复版本更新后损坏的旧 Mod，还是解决原神 Mod 运行时的报错问题，MIMITools 都能提供对应的一体化工作流。
