# 结构体

Rust 中没有面向对象语言中类似**类**的东西, 通过结构体与定义在结构体上的函数和方法实现类似需求.

结构体如下定义:

```Rust
struct StrName {
    str_element_1: Type1,
    str_element_2: Type2,
    etc...
}
```
这里定义了名为 `StrName` 的结构体, 其含有若干元素, 名为 `str_element_1` 等, 分别以 `Type1` 等为类型.

可以看到结构体本身命名规范为大 CamelCase, 分量为 snake_case, 不遵循会被警告.

:::details 规避警告
```Rust
#[allow(nonstandard_style)]
struct str_name {
    str_element_1: Type1,
    #[allow(non_snake_case)]
    StrElement_2: Type2,
}
```
:::

定义之后允许绑定变量为该结构体类型:

```Rust
// let e1: Type1 = something;
// let e2: Type2 = something;
// etc...
let var = StrName {
    str_element_1: e1,
    str_element_2: e2,
    etc...
}
```

举例, 定义一个学生信息结构体:

```Rust
struct Student {
    age: u8,        // TODO: 或许会无法处理年龄大于 127 年的学生.
    name: String,
    gender: bool,   // TODO: 这里暂时用布尔值模拟男女, 无法处理武装直升机和沃尔玛购物袋.
    height: f32,    // 米
    weight: f32,    // 千克
}
```
