# 教学资源

全部PNG为本次原创程序绘制的合成UV示意，非游戏解包资产、非第三方图片、非模型生成质量测试。

`*-data.png`是不含图例的原始RGBA教学数据图；主PNG是合成图与RGBA拆通道的说明图。synthetic-diffuse与synthetic-regions为同一合成UV的输入与区域示意。数字仅对应文档教学预设，不是原游戏测量值或通用材质ID规则。

鸣潮normal-packed示意只说明独立确认RG法线+B粗糙+A金属契约后的通道结构，不能作为文档所核查HoyoToon复杂BA路径的推荐参数。

来源与校验信息见manifest.json；资源随本站文档使用，外部项目和游戏资产权利不受此声明影响。
