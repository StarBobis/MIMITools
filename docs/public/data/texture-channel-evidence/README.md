# Texture-channel evidence

This inventory describes pinned community reproduction implementations, **not every native game build**. `verified_scoped` means the cited sampling contract was reviewed; it is not runtime or native-game validation. `verified_unused` means unused in the cited implementation (including explicitly disconnected or discarded output paths).

## Reproduce validation

From the repository root:

```sh
bun run test:channels --complete
bun run test:channel-sources
bun run test:channel-scope
# Independently compare the full selected GitHub trees (requires gh):
bun run test:channel-scope --remote
bun run test:channel-sources --remote
# Alternative transport when raw.githubusercontent.com is unavailable (requires gh):
bun run test:channel-sources --remote --github-api
bun run docs:build
bun run test:channel-site
```

The complete gate rejects pending bindings. The source validator checks guide anchors, RGBA descriptions (or an unused-channel ledger), direct evidence links and immutable declaration URLs. Remote mode independently retrieves each declaration-bearing file at its recorded commit and compares its complete texture-name set, including Endfield's expanded bloom-target macro calls. It checks recorded declaration line numbers as well. No ignored local research cache is needed.

Current declaration scope: Genshin88, HI3 19, Star Rail44, ZZZ17, Wuwa36, Endfield57 (261 game/binding entries in 18 declaration files). Genshin includes its separate particle implementation. Shared Bloom/postprocessing declarations are included in Genshin, Star Rail and Wuwa; existing names with distinct roles carry `additional_guide_anchors`, which the validator checks independently. Counts deduplicate names within each game, not across games. Endfield includes internal HLSL/fxsub resource declarations and runtime render targets; the D24S8 target deliberately has no ordinary RGBA channels. These counts are not claims of all native-game texture assets.

`source-scope.json` includes all selected HLSL/shader/fxsub files in the pinned HoyoToon `Shaders/` and Endfield `EndfieldMME/internal/` prefixes, including files declaring no textures. The ledger was generated by retrieving original GitHub bytes and checking Git blob SHA-1 before parsing declarations. `test:channel-scope --remote` verifies the complete GitHub tree path sets and blob IDs, so an omitted declaration file cannot silently pass the known-file validator. This remains a selected implementation scope, not a native asset inventory.

The inventory is reviewed evidence data. To add or change a binding, update its name/kind/declaration path/line/commit/URL/status/guide anchor together with the guide. Remote verification fails on missing or extra names. To extend source scope, include every additional declaration file and its entire declared-name set, not only bindings already described in prose.

`wuwa-auxiliary.json` stores compact node topology from the pinned Gustling Waters Blender reproduction. It contains no original texture pixels or private source paths. Disconnected nodes and missing custom-node execution are documented as such, not treated as proof of native-game meanings.

`endfield-extra.json` stores compact E/M and custom face-mask downstream topology from AKE's pinned PBRToonBase/BaseFace groups. Integer node IDs are original per-tree indices, avoiding corrupted labels in an older inspection cache. It confirms E RGB multiply/add, M RGB RS modulation, and that the first custom mask's R enters the threshold (second operand) rather than the tested value. Image Alpha outputs are disconnected in these paths. No original image pixels, file paths or full third-party project are included; unavailable custom-engine execution remains explicitly outside the evidence claim.

`endfield-image-ledger.json` classifies every TEX_IMAGE node in the observed pinned AKE audit: 58 nodes, 53 distinct observed labels. It stores the original tree/node indices, outgoing Color/Alpha socket IDs and saved color space when an image is present. Each entry points to a guide section, whose AKE/MME boundaries must still be respected; this identity ledger is not a claim that all same-suffix images have identical renderer contracts.

`importer-crosswalk.json` records 38 reviewed classifier/JSON aliases for Genshin, Wuwa, ZZZ and Endfield. A slot assignment is not a new RGBA contract: aliases link to scoped consumers and explicitly preserve uncertain/heuristic matching and material-specific differences (including AKE's inconsistent RD import color-space branches).

The deployment runs complete/offline source checks before building and structural built-site checks afterward. `test:channel-site` verifies all six guides' rendered anchors, local navigation, image-file existence and byte-identical evidence JSON exports. It does not claim browser screenshot inspection or native-game renderer validation.

The guides distinguish function-internal sampling from final output, debug-only branches, consumed versus ignored channels, linear data versus sRGB colors, and version-specific UV/encoding layouts. Generated teaching images and prompt presets are not original game assets or renderer validation.
