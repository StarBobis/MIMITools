# 🎨 ComfyUI 贴图工作流

ComfyUI 是一种组织模型与后处理步骤的节点工具，**不是理解游戏通道的替代品，也不是唯一方案**。先读[贴图通道与AI生成：基础与验收](../TextureChannelGuide/TextureChannelGuide.md)，再选择适合自己的生成工具。

## 什么可以生成

支持图像编辑的模型可以根据Diffuse提出法线、材质分区和控制遮罩候选；具体输出由模型与工作流决定。角色Toon Shader的LightMap经常是高光、阴影阈值与材质ID的packed数据，不是场景烘焙照明。不能把普通AO或PBR贴图直接套进所有游戏。

## 不必拥有顶级GPU

本地模型的显存、速度与内存要求取决于模型、量化和分辨率，不能一概而论。云端图像编辑、手工通道编辑、Blender烘焙、Substance及脚本都可作为替代或组合。云模型须检查素材上传权限、费用与使用许可；有Mesh的法线烘焙往往比仅看Diffuse猜凹凸更有依据。

## 推荐流程

1. 确认目标游戏/材质/Shader、贴图角色、通道与色彩空间。
2. 按游戏页的一段式提示词生成候选，或先生成语义分区。
3. 在外部工具精确设置常量、量化材质ID、继承Alpha、打包通道。
4. 输出PNG/TGA编辑成果，检查UV与通道；最终格式按游戏加载器要求。
5. 在实际材质中做不同光向、视角、距离的渲染对照，不能只凭图片好看验收。

工作流JSON、提示词和模型结果都不承诺逐像素UV配准或原游戏Shader兼容；最终数据图与模型原输出应分别保存。
