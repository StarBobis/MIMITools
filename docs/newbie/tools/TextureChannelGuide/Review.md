## 自行审查发现并处理的问题

| 问题 | 处理 |
| --- | --- |
| 原神LightMap R同时参与普通高光与金属分支 | 不简化为纯金属度；提示词限定分支并避免未知阈值 |
| 星铁Alpha索引采用floor(8×A) | 不要求Alpha255；使用区间内部代表值，强调原索引/参数组 |
| 崩坏三Part1/Part2高光和区域公式不同 | 分开说明；不交换两套精确数值 |
| ZZZ旧版辅助功能打包在三张Alpha | 给出新/旧布局对照，撤销“所有ZZZ Alpha都未用”的泛化 |
| ZZZ脸LightTex与身体RG法线不同 | 独立表述脸R阈值、G高光、B条件轮廓、A AO |
| 鸣潮界面Metallic(G)标签与实际代码冲突 | 以RG法线实际读取为准，BA复杂高光作用保留限定 |
| 鸣潮TypeMask B变量存在但未影响该函数最终输出 | 标为未证实生效，不写成确定Ramp控制 |
| 终末地旧社区表与公开MME的BA顺序相反 | 保留社区署名，加入风险提示；分别记录不同契约 |
| 终末地脸Diffuse A与独立Skin路径不一致 | 脸AO有证据；独立Skin未确认，不外推 |
| 终末地头发HN BA也是法线，P.r不等于金属 | 明确双法线与头发专属层混合，禁止Alpha全白 |
| 终末地头发某些路径显式转Property RGB色彩空间 | 不套无条件Non-Color字节规则，要求核查具体路径 |
| 示例ID与物理材质没有固定对应 | 教学图/数字明确标注预设，不作为游戏测量值 |
| 模型无法保证精确常量、Alpha、UV | 区分候选生成与外部定值/通道继承，不承诺提示词即生产成品 |

- 正文固定版本源码引用逐一对应本次取回的文件，提交号与行号范围有效；正文共70处固定源码引用。

- 七组相邻资源目录含原创合成示意；PNG可解码，尺寸与SHA256清单一致。

- VitePress完整生产构建通过，页面与侧边栏可生成；现有KaTeX模块格式与bundle大小警告不是新文档错误。
- 新增页不复制第三方Shader源码或来源不明的游戏解包贴图；示意资源不冒充模型生成实测。
